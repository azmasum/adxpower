1. Browser Profiles

Browser Profiles are isolated Chromium instances, each with a unique fingerprint. Use them to manage multiple accounts safely without detection.

1.1 Creating a New Profile

1Click New Profile button in the top-right corner of the Profiles page.
2Enter a Profile Name (e.g., "Amazon Buyer Account - 02").
3Select a Group: E-commerce, Social Media, or Ads.
4Choose an Operating System from 15 options (Windows 10/11, macOS Sonoma/Ventura/Monterey, Ubuntu, Debian, Fedora, Arch, ChromeOS, Android, iOS).
5Select a Browser Fingerprint from 25 options (Chrome, Firefox, Safari, Edge, Brave, Opera, Vivaldi, Waterfox).
6Optionally assign a Proxy from the dropdown (only active proxies appear).
7Add Tags (comma-separated, e.g., "Amazon, US, Buyer").
8Click Create Profile.

1.2 Starting a Profile

Click the Open button (green play icon) next to any stopped profile. A Chromium browser window launches with the profile's unique fingerprint. The status indicator changes to green "Running".

1.3 Stopping a Profile

Click the Close button (red square icon) on any running profile. The browser window closes and the profile returns to "Stopped" status.

1.4 Editing a Profile

Click the Edit button (pencil icon) to modify name, group, OS, browser, tags, or assigned proxy. Click Save Changes to apply.

1.5 Deleting a Profile

Click the Delete button (trash icon). A confirmation dialog appears. Confirm to move the profile to trash.

1.6 Filtering & Searching

  • Group Filter: Use the dropdown to filter by All Groups, E-commerce, Social Media, or Ads
  • Search: Type in the search box to filter profiles by name
  • Sort: Click column headers to sort ascending/descending
  • Bulk Select: Use checkboxes to select multiple profiles for batch operations

1.7 Proxy Display

If a profile has an assigned proxy, the proxy details appear in the table: protocol, host, port, country flag, and latency. Click Check Connection to verify the proxy is still active.

Tip: Each profile gets its own user data directory, so cookies, history, and extensions are completely isolated between profiles.

2. Proxy Management

Manage proxies for your browser profiles. AdxPower supports HTTP, HTTPS, SOCKS4, and SOCKS5 protocols.

2.1 My Proxies

View all your proxies in a table. Each proxy shows host, port, protocol, country, status, latency, and assigned profiles.

Adding a Proxy Manually

1Click Add Proxy in the My Proxies tab.
2Enter Host (IP or domain) and Port.
3Select Protocol: HTTP, HTTPS, SOCKS4, or SOCKS5.
4Optionally enter Username and Password for authenticated proxies.
5Click Save.

Scraping Free Proxies

1Click Scrape Proxies.
2Select a Country filter (US, GB, DE, FR, CA, JP, AU, NL, SG, KR, or All).
3Select a Protocol (or All).
4Click Start Scrape. Proxies are fetched from 3 sources: ProxyScrape API, GeoNode API, and GitHub.
5Scraped proxies appear in the table with "untested" status.

Checking Proxy Connectivity

Click the Check button on any proxy. The system validates the connection via ipapi.co and updates: IP address, country, latency, and status (active/dead).

2.2 Proxy Checker (Bulk Import)

Paste multiple proxies (one per line, format: host:port:username:password) and check them all at once. Results show live status for each proxy.

2.3 Assigning a Proxy to a Profile

1Open the Edit Profile modal on any profile.
2Select a proxy from the Proxy dropdown.
3Click Save Changes.

The profile will now route all traffic through the assigned proxy when started.

Tip: New profiles automatically get an available proxy assigned if one is available.

3. Fingerprint Manager

Generate, view, and manage browser fingerprints. Each fingerprint contains spoofed data for WebGL, canvas, audio, fonts, and more.

3.1 Generating a Fingerprint

1Select an Operating System from the generator panel.
2Select a Browser version.
3Click Generate. A unique fingerprint is created with random but realistic values.

3.2 Viewing Fingerprint Details

Click any saved fingerprint to view its full JSON structure including:

  • WebGL: Vendor and renderer (e.g., "NVIDIA GeForce RTX 4090")
  • Canvas: Noise seed for consistent canvas fingerprint
  • Audio: AudioContext noise parameters
  • Fonts: Allowed/blocked font list
  • WebRTC: IP leak prevention settings
  • Timezone and Locale settings

3.3 Exporting

Click Copy JSON to copy the full fingerprint to your clipboard for use in external tools.

4. RPA Automation

Automate browser tasks with a visual step builder. Create flows that navigate, click, type, and extract data from websites.

4.1 Building a Flow

1Go to Automation → RPA Robot.
2Select a Target Profile from the dropdown.
3Click action buttons in the left panel to add steps:

CLICKClick an elementCSS Selector
DOUBLE_CLICKDouble-click an elementCSS Selector
RIGHT_CLICKRight-click an elementCSS Selector
TYPEType text into inputCSS Selector + Text

EXTRACT_TEXTExtract text from elementCSS Selector
4Configure each step's parameters in the center panel.
5Reorder steps by dragging (or use up/down buttons).
6Click Run Flow to execute. Monitor progress in the right panel log.

4.2 Example: Google Search Automation

1NAVIGATE → https://google.com
2CLICK → textarea[name='q']
3TYPE → selector: textarea[name='q'], text: AdxPower browser
4PRESS_KEY → Enter
5WAIT → 3000 ms
6SCREENSHOT → capture results
Tip: If the profile browser is not running, RPA will automatically start it before executing steps.

5. Synchronizer (Master-Slave)

Control multiple browser profiles simultaneously. Actions performed on the master profile are replicated to all slave profiles.

5.1 Starting Synchronization

1Go to Automation → Synchronizer.
2Select a Master Profile (the profile you'll control from).
3Enable the sync options you want (see below).
4Click Start Sync. All other profiles auto-start as slaves.

5.2 Sync Options

OptionDescription
ClicksReplicate mouse clicks
TypingReplicate keyboard input
ScrollReplicate page scrolling
NavigationReplicate URL navigation
Form FillReplicate form field inputs
DropdownsReplicate dropdown selections
Mouse MoveReplicate mouse movement
Right ClickReplicate context menu actions
File UploadReplicate file upload dialogs
Drag & DropReplicate drag-and-drop actions
HotkeysReplicate keyboard shortcuts
ZoomReplicate page zoom in/out

5.2 Stopping Synchronization

Click Stop Sync. All slave profiles are stopped automatically.

Warning: Ensure all slave profiles have the same website open as the master for accurate replication.

6. Cookie Robot

Import cookies to age your profiles and make them look like real, established browsers.

6.1 Importing Cookies

Option A: Paste Cookies

1Go to Cookie Robot.
2Select a Target Profile.
3Paste cookies in JSON format or Netscape format into the text area.
4Click Import Cookies.

Option B: Generate Cookies

1Click Generate to create realistic cookies.
2Cookies are generated for 8 major platforms: Google, YouTube, Facebook, Amazon, Twitter, LinkedIn, Instagram, TikTok.
3Review and click Import.

Option C: Upload File

Click Upload File and select a .json or .txt cookie file from your computer.

6.2 Warmup Bot

The warmup bot visits real websites to age your profile and build a realistic browsing history.

1Select a Target Profile.
2Check the websites you want to visit: Google, YouTube, Facebook, Amazon, Twitter, LinkedIn, Instagram, TikTok.
3Click Start Warmup.
4Monitor progress: a progress bar and live log show each site visit with timestamps.
5The bot automatically scrolls, pauses, and navigates to simulate real user behavior.

6.3 Exporting Cookies

Click Export Cookies to download the current profile's cookies as a JSON file.

2Click Install on any extension card.

7.3 Custom Extensions

1Click Upload Custom.
2Select a .crx or .zip extension file.
3Enter a name and description.
4Click Upload.

7.4 Assigning to Profiles

1Click the Assign button on an extension.
2Select one or more profiles from the list.

7.5 Enabling/Disabling

Use the toggle switch on any assigned extension to enable or disable it for a specific profile without unassigning.

8. License Manager

Manage your AdxPower license. Activate, deactivate, transfer, or start a free trial.

8.1 Activating a License

1Go to License Manager in the sidebar.
2Enter your License Key (format: XXXX-XXXX-XXXX-XXXX).
3Click Activate.
4Your license is now bound to this machine. The active license details appear: key, hardware ID, max profiles, expiry date.

8.2 Starting a Free Trial

1Click Start Free Trial on the License Manager page.
2A 1-day trial activates with 3 max profiles.
3A countdown banner appears at the top of the app showing remaining time.
Warning: Only one trial is allowed per hardware ID. After expiry, you must purchase a plan.

8.3 Transferring a License

1On the old machine, click Deactivate to unbind the license from this hardware.
2On the new machine, enter the same license key and click Activate.

8.4 Offline Activation

For machines without internet access:

1On an offline machine, note the hardware ID shown in License Manager.
2On an online machine, use the Offline Activation section to generate an activation key.
3Enter the generated key on the offline machine to activate.
